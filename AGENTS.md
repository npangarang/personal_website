# AGENTS.md

Personal portfolio site — a single-page Vite/React/TS app styled as an interactive zsh terminal. Owner: Neel Panging.

## Stack

- Vite 5 (`@vitejs/plugin-react-swc`), React 18, TypeScript 5
- Tailwind CSS 3 + shadcn/ui (Radix primitives, baseColor slate, CSS variables in `src/index.css`)
- Vitest + jsdom + `@testing-library/react` (dev only)
- Path alias `@/*` → `./src/*` (Vite, vitest, and all three tsconfigs)

## Commands

```sh
npm i              # install (README pins npm; bun.lockb is leftover, ignore it)
npm run dev        # dev server at http://localhost:8080  (vite.config.ts)
npm run build      # production build → dist/
npm run build:dev  # dev-mode build (unminified)
npm run preview    # serve dist/
npm run lint       # ESLint 9 flat config (eslint.config.js), ignores dist/
npm run test       # vitest run (one-shot)
npm run test:watch # vitest watch mode
```

There is **no `typecheck` script**. To typecheck, run `npx tsc -p tsconfig.json` (it uses project references to `tsconfig.app.json` + `tsconfig.node.json`). Don't assume a `tsc` script exists.

Verification order before commit: `npm run lint` → `npx tsc -p tsconfig.json` → `npm run test` → `npm run build`.

## Entry points & layout

- App entry: `src/main.tsx` → `src/App.tsx` → `src/pages/Index.tsx` → `src/components/Terminal.tsx`
- `App.tsx` mounts React Router. **Any new `<Route>` must be added ABOVE the `path="*"` catch-all** (already marked with a comment in `src/App.tsx:19`).
- `src/components/Terminal.tsx` is the interactive core — command parsing, history, tab-complete, typewriter animation.
- `src/data/resumeData.ts` is the **single source of truth for all content** (about, education, skills, experience, contact, ASCII banner, command list). Edit there, not in components.
- `src/components/ui/*` is generated by shadcn; don't hand-edit unless adding a new component via the CLI.
- `public/resume.pdf` is the downloadable resume (referenced by `/resume.pdf` from the `resume` command in `Terminal.tsx:225-233`).

## Terminal markup format (non-obvious)

Output strings in `src/data/resumeData.ts` and `Terminal.tsx` use a custom ANSI-style markup parsed by `parseColour` in `src/components/Terminal.tsx:14-70`:

- `\x1b[cyan]...\x1b[/cyan]`, `\x1b[green]...\x1b[/green]`, `\x1b[amber]...\x1b[/amber]`, `\x1b[bold]...\x1b[/bold]`
- `\x1b[cmd:<name>]...\x1b[/cmd]` renders the inner text as a clickable command chip (callback goes through `executeCommand`).

Keep these tokens when adding content. The parser is the only consumer — there is no separate styling layer.

## Dev server quirks

- Bound to host `::` and port `8080` (see `vite.config.ts`).
- HMR overlay is **disabled** — runtime errors won't pop a fullscreen overlay; check the terminal/console instead.
- `dist/` is gitignored but currently present in the working tree (legacy). Don't commit it; `npm run build` will refresh it.

## Testing

- Config: `vitest.config.ts` — jsdom env, globals on, setup file `./src/test/setup.ts`, match pattern `src/**/*.{test,spec}.{ts,tsx}`.
- Setup file polyfills `window.matchMedia` (needed by some Radix components) and imports `@testing-library/jest-dom`.
- Only one real test exists: `src/test/example.test.ts` (trivially true). Testing is wired up but unused; expect to add tests from scratch.

## ESLint

Flat config in `eslint.config.js`. Important relaxation: `@typescript-eslint/no-unused-vars` is **off** by design. Don't "fix" it. `dist/` is ignored.

## Repo gotchas

- `.devcontainer/devcontainer.json` is a stale Python 3 / Streamlit template from before the rewrite — **ignore it**, it does not describe this app. Don't run anything from it.
- `bun.lockb` and `package-lock.json` both exist in the repo. README says npm and `package.json` is the source of truth — don't introduce `bun.lock` or `pnpm-lock.yaml` changes.
- `.lovable/plan.md` contains the original design plan (interactive zsh terminal with `help/about/education/skills/experience/contact/clear` commands). Useful for intent; not authoritative for current behavior.
- There is no CI (no `.github/` directory). No PR template, no release flow — manual push to `main`.
- TypeScript is intentionally lenient: `strict: false`, `noImplicitAny: false`, `noUnusedLocals: false`, `noUnusedParameters: false` (in `tsconfig.app.json`). Don't tighten these globally without coordination.

## Common edits

- **Change copy / resume content** → edit `src/data/resumeData.ts`. Keep the markup tokens intact.
- **Add a terminal command** → add an entry to `AVAILABLE_COMMANDS`, add a branch in `runCommand` (`src/components/Terminal.tsx:73-143`), and add a chip in `COMMAND_CHIPS` (`src/components/Terminal.tsx:189`) if it should appear in the bottom row.
- **Replace the resume PDF** → drop a new file at `public/resume.pdf` (or update the `download` attribute in `Terminal.tsx:228`).
- **Add a page route** → add `<Route>` in `App.tsx` **above** the `*` route, then add the component under `src/pages/`.
- **Add a shadcn component** → use the shadcn CLI; config is in `components.json` (style `default`, aliases point into `src/`).
